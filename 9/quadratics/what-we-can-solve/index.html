Quadratic equations: what we can already solve

Before any new method: which quadratic equations can you solve already, and why does that work?

PUPPCommon coreLevels 1–3 · threshold to basicAbout 45 min · 1 class periodProgramme 32.1.1.1, 31.2.2
PDF
Handout lesson summary, examplesWorksheet check items, exam taskAnswer key answers, marking, teacher notes
Goal

In this lesson

Write any quadratic equation in the form ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0, and solve those that are a product equal to zero or a square equal to a number.

By the end of the lesson

  • I can write a quadratic equation in the form ax² + bx + c = 0, name a, b and c with their signs, and tell a complete equation from an incomplete one.
  • I can solve an equation whose left side is a product of linear factors and whose right side is 0, and an equation of the form (x + p)² = d.

What you need from before

  • Linear equations and forming an equation
  • Square roots
  • Expanding brackets and the square formulas
  • Incomplete quadratic equations

1 class period · about 45 min

How easy an equation is depends on how it is written. Written as (D), it takes one line.

The general form

An equation that can be written as

ax2+bx+c=0,a≠0,ax^2 + bx + c = 0, \qquad a \ne 0,ax2+bx+c=0,a=0,

is a quadratic equation. The numbers aaa, bbb and ccc are its coefficients: aaa is the coefficient of x2x^2x2, bbb of xxx, and ccc is the constant term.

To read them, first move every term to the left side and collect like terms. Then read each coefficient with its sign:

  • (E) x2−4x−5=0x^2 - 4x - 5 = 0x2−4x−5=0: a=1a = 1a=1, b=−4b = -4b=−4, c=−5c = -5c=−5.
  • (A) 3x2=273x^2 = 273x2=27 becomes 3x2−27=03x^2 - 27 = 03x2−27=0: a=3a = 3a=3, b=0b = 0b=0, c=−27c = -27c=−27.
  • (B) x2+4x=0x^2 + 4x = 0x2+4x=0: a=1a = 1a=1, b=4b = 4b=4, c=0c = 0c=0.

Why a≠0a \ne 0a=0? If a=0a = 0a=0, the x2x^2x2 term disappears and the equation is not quadratic any more (it is linear if b≠0b \ne 0b=0).

Complete, incomplete, or not quadratic at all

A quadratic equation is incomplete if b=0b = 0b=0 or c=0c = 0c=0, like (A) and (B). You solved these in grade 8. If b≠0b \ne 0b=0 and c≠0c \ne 0c=0, it is complete, like (E).

Decide only after tidying. Some equations only look quadratic:

(x+1)2=x2+3(x + 1)^2 = x^2 + 3(x+1)2=x2+3

2x−2=02x - 2 = 02x−2=0

The x2x^2x2 cancels, so this equation is linear (x=1x = 1x=1).

A product equal to zero

Zero-product rule. A product is equal to 000 if and only if at least one of its factors is 000:

p⋅q=0  ⟺  p=0  or  q=0.p \cdot q = 0 \iff p = 0 \ \text{ or } \ q = 0.p⋅q=0⟺p=0  or  q=0.

Why: if p≠0p \ne 0p=0, divide both sides by ppp and get q=0q = 0q=0.

So (C) splits into two linear equations:

(x−3)(x+5)=0(x - 3)(x + 5) = 0(x−3)(x+5)=0
zero-product rule
x−3=0  or  x+5=0x - 3 = 0 \ \text{ or } \ x + 5 = 0x−3=0  or  x+5=0
solve each
x=3  or  x=−5x = 3 \ \text{ or } \ x = -5x=3  or  x=−5

Grade 8’s x2+4x=0x^2 + 4x = 0x2+4x=0 uses the same rule: x(x+4)=0x(x + 4) = 0x(x+4)=0, so x=0x = 0x=0 or x=−4x = -4x=−4.

Only zero works like this. From p⋅q=6p \cdot q = 6p⋅q=6 you cannot find ppp: 1⋅61 \cdot 61⋅6, 2⋅32 \cdot 32⋅3 and 12⋅12\tfrac{1}{2} \cdot 1221​⋅12 all give 666. You only learn that p≠0p \ne 0p=0.

A square equal to a number

In (x+p)2=d(x + p)^2 = d(x+p)2=d, the bracket x+px + px+p is a number whose square is ddd. There are three cases:

  • d>0d > 0d>0, e.g. (x−2)2=9(x - 2)^2 = 9(x−2)2=9:   x−2=3\;x - 2 = 3x−2=3 or x−2=−3x - 2 = -3x−2=−3. Two roots, x=5x = 5x=5 and x=−1x = -1x=−1.
  • d=0d = 0d=0, e.g. (x−2)2=0(x - 2)^2 = 0(x−2)2=0:   x−2=0\;x - 2 = 0x−2=0. One root, x=2x = 2x=2.
  • d<0d < 0d<0, e.g. (x−2)2=−1(x - 2)^2 = -1(x−2)2=−1: no real number has a negative square. No real roots.

We always look for roots among the real numbers. That is why the third case is called no real roots.

In general, for d>0d > 0d>0: x+p=dx + p = \sqrt{d}x+p=d​ or x+p=−dx + p = -\sqrt{d}x+p=−d​. Write both equations out, then solve each one. That avoids sign slips.

What we can solve so far

  • Incomplete, ax2+bx=0ax^2 + bx = 0ax2+bx=0, like x2+4x=0x^2 + 4x = 0x2+4x=0: write x(ax+b)=0x(ax + b) = 0x(ax+b)=0 and use the zero-product rule.
  • Incomplete, ax2+c=0ax^2 + c = 0ax2+c=0, like 3x2=273x^2 = 273x2=27: bring it to x2=dx^2 = dx2=d.
  • A product of linear factors equal to 000, like (x−3)(x+5)=0(x - 3)(x + 5) = 0(x−3)(x+5)=0: the zero-product rule.
  • A square equal to a number, like (x−2)2=9(x - 2)^2 = 9(x−2)2=9: x+p=dx + p = \sqrt{d}x+p=d​ or x+p=−dx + p = -\sqrt{d}x+p=−d​.
  • Other equations, like x2−4x−5=0x^2 - 4x - 5 = 0x2−4x−5=0: we have no general way yet to choose a useful form.

(E) was easy because we already knew its form (D).

Summary

What to remember

  • A quadratic equation can be written as ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 with a≠0a \ne 0a=0. Move every term to one side first, then read aaa, bbb, ccc with their signs.
  • It is incomplete if b=0b = 0b=0 or c=0c = 0c=0, and complete otherwise. Decide after tidying: sometimes the x2x^2x2 cancels.
  • Zero-product rule: p⋅q=0p \cdot q = 0p⋅q=0 exactly when p=0p = 0p=0 or q=0q = 0q=0. It works only with 000 on the other side.
  • A square equal to a number, (x+p)2=d(x + p)^2 = d(x+p)2=d:
    • d>0d > 0d>0: x+p=dx + p = \sqrt{d}x+p=d​ or x+p=−dx + p = -\sqrt{d}x+p=−d​, so there are two roots;
    • d=0d = 0d=0: one root, x=−px = -px=−p;
    • d<0d < 0d<0: no real roots.
  • Check a root by substituting it into the original equation.

Teacher notes

For the teacher

Pupils can say: “I can write a quadratic equation as ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 and read aaa, bbb, ccc with their signs; I can tell a complete equation from an incomplete one; I can solve a product equal to zero and a square equal to a number.”

Where this lesson sits. Since V-594, the definition of a quadratic equation and the incomplete equations are grade 8 content (31.2.2). This lesson collects that knowledge, names the general form, and adds two easy types: a product of linear factors equal to 000, and (x+p)2=d(x + p)^2 = d(x+p)2=d. The hook sets up lesson 1.2: (E) became easy because it could be rewritten as (D). Can that always be done?

Common mistakes and what helps

  • Reading bbb and ccc before moving the terms to one side (7−3x2=2x7 - 3x^2 = 2x7−3x2=2x read as b=2b = 2b=2). Insist on "…=0\ldots = 0…=0" first.
  • Signs in the zero-product rule: x+6=0x + 6 = 0x+6=0 gives x=−6x = -6x=−6; 3x−1=03x - 1 = 03x−1=0 gives x=13x = \tfrac{1}{3}x=31​, not 333.
  • Using the rule when the right side is not 000 (item c7). Ask: “Why does the rule need a 000?”
  • Forgetting the negative case in (x+p)2=d(x + p)^2 = d(x+p)2=d (c5), or “taking the root” of a negative number (c6).
  • Dividing by xxx, which loses the root x=0x = 0x=0 (r2). Lesson 1.5 comes back to this.
  • Calling an equation incomplete just because it is short (x2+x=1x^2 + x = 1x2+x=1), or because it is easy to solve ((x−1)2=0(x - 1)^2 = 0(x−1)2=0).
