Dviejų iš eilės einančių natūraliųjų skaičių kvadratų suma lygi 181. Rask tuos skaičius.

Mažesnįjį skaičių pažymėk nnn. Koks tada kitas skaičius?
n2+(n+1)2=181n^2 + (n + 1)^2 = 181n2+(n+1)2=181.
Atskliausk ir suprastink: 2n2+2n−180=02n^2 + 2n - 180 = 02n2+2n−180=0, todėl n2+n−90=0n^2 + n - 90 = 0n2+n−90=0.
Vertinimas: pažymėk, ką tavo sprendime pavyko atlikti
  1. Sudaro lygtį, pvz., n2+(n+1)2=181n^2 + (n+1)^2 = 181n2+(n+1)2=181.
  2. Pertvarko ją į pavidalą n2+n−90=0n^2 + n - 90 = 0n2+n−90=0.
  3. Išsprendžia lygtį: n=9n = 9n=9 arba n=−10n = -10n=−10.
  4. Atmeta n=−10n = -10n=−10 (tai ne natūralusis skaičius) ir parašo atsakymą: 9 ir 10.
Sprendimas

Tegu ieškomi skaičiai yra nnn ir n+1n + 1n+1. Tada n2+(n+1)2=181n^2 + (n+1)^2 = 181n2+(n+1)2=181, t. y. 2n2+2n+1=1812n^2 + 2n + 1 = 1812n2+2n+1=181 ir n2+n−90=0n^2 + n - 90 = 0n2+n−90=0.

D=1+360=361=192D = 1 + 360 = 361 = 19^2D=1+360=361=192, todėl n=−1±192n = \dfrac{-1 \pm 19}{2}n=2−1±19​: n=9n = 9n=9 arba n=−10n = -10n=−10.

Skaičiai yra natūralieji, todėl n=9n = 9n=9. Atsakymas: 9 ir 10. Patikrinimas: 81+100=18181 + 100 = 18181+100=181.

Santrauka

Ką verta įsiminti

  • Pirmiausia užrašyk lygtį pavidalu ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0, tada nustatyk aaa, bbb, ccc kartu su jų ženklais.
  • Diskriminantas D=b2−4acD = b^2 - 4acD=b2−4ac parodo, kiek sprendinių turi lygtis:
    • D>0D > 0D>0: du sprendiniai;
    • D=0D = 0D=0: vienas sprendinys, x=−b2ax = -\frac{b}{2a}x=−2ab​;
    • D<0D < 0D<0: realiųjų sprendinių nėra.
  • Sprendiniai: x1,2=−b±D2ax_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}x1,2​=2a−b±D​​. Ši formulė gaunama išskiriant pilnąjį kvadratą.
  • Patikrink sprendinį: įrašyk jį į lygtį. Tekstiniame uždavinyje palik tik tuos sprendinius, kurie tinka pagal sąlygą.
